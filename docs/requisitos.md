# FASHION RUNWAY
## Plataforma Web de Moda y Pasarelas

### 1. Descripción del proyecto
Plataforma web interactiva para que estudiantes de diseño de moda puedan exhibir sus colecciones, mostrar videos de pasarelas, ofrecer prendas y gestionar invitaciones digitales para eventos escolares.

### 2. Objetivo general
Desarrollar una plataforma web atractiva, funcional y adaptable que permita promocionar las creaciones de los estudiantes de diseño de moda.

### 3. Requisitos funcionales

RF01. Mostrar una página principal de bienvenida.

RF02. Mostrar un catálogo visual de prendas.

RF03. Mostrar nombre, descripción y precio de cada prenda.

RF04. Permitir solicitar la compra o reserva de prendas.

RF05. Mostrar videos de pasarelas mediante YouTube.

RF06. Permitir solicitar invitaciones digitales.

RF07. Generar un folio único para cada invitación.

RF08. Mostrar un código QR asociado a la invitación.

### 4. Requisitos no funcionales

RNF01. Diseño adaptable a computadoras y celulares.

RNF02. Interfaz intuitiva y fácil de utilizar.

RNF03. Navegación rápida.

RNF04. Código organizado y documentado.

RNF05. Sitio web publicado mediante GitHub Pages.

### 5. Tecnologías

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages
- YouTube para los videos de pasarelas.
